# ZzzDlssg Launcher

《绝区零》DLSS 帧生成（DLSS-G）解锁启动器：把 NVIDIA GeForce RTX 20 / 30 系显卡伪装成
RTX 4090 / 5090，让 `dlssg_sm86` 的 SM75 / SM86 内核在游戏里启用 DLSS 帧生成。

- **不往游戏目录写任何文件**：全部通过进程注入加载，游戏目录保持干净。
- **交付物只有一个 exe**：注入插件与内核由启动器在「下载插件」时下载、校验、打补丁、安装。
- **源码不公开**：本仓库只发布编译好的二进制与使用说明。

当前版本 **v0.0.1**。

## 快速开始

1. 把 zip 解压到一个**独立文件夹**（不要放进游戏目录），双击 `ZzzDlssgLauncher.exe`，UAC 点「是」。
2. 首次运行只有 exe，卡片 02「文件校验」是 **0/7 红灯**、日志写着「插件尚未安装」——点卡片里的
   **「下载插件」**，等它走完：测速 → 下载 → 校验 → 解包 → 打补丁 → 复核；完成后变成 **7/7 绿灯**。
   同一次启动中 `config.ini` 和 `zzzdlssg.log` 会自动生成，不用手动准备。
3. 确认「游戏目录」已自动找到 `ZenlessZoneZero Game`；没找到就点「手动指定」选 `ZenlessZoneZero.exe` 所在目录。
4. 在「伪装目标」里选 **NV40XX**（显示为 RTX 4090）或 **NV50XX**（显示为 RTX 5090），勾选自己的显卡。
5. 点底部 **「开始游戏」**：启动器用 `-use-d3d12` 拉起游戏并自动注入。
6. 也可以从 HoYoPlay 启动，但启动参数要加 `-use-d3d12`。

游戏起来后，按钮右侧会显示 **运行中 · PID xxxx · 帧生成已就绪**，「运行日志」里同时出现
**帧生成注入成功 · PID xxxx**（失败会写 **帧生成注入失败：原因**）。此时按钮变成「退出游戏」。

> 首次运行会提示「未知发布者」，因为用的是自签测试证书（`CN=DLSSG Throwaway Test`），属于预期现象。

## 界面

| 区块 | 作用 |
|---|---|
| 01 游戏目录 | 自动查找国服 / 国际服安装位置，命中的那个标签高亮 |
| 02 文件校验 | 对安装后的 7 个 DLL 做 SHA-256 比对（基准编在 exe 里）；状态灯：绿 = 全部匹配，黄 = 安装中 / 校验中，红 = 未安装或校验失败。副按钮「下载插件」是安装 / 修复入口 |
| 03 伪装目标 | NV40XX = RTX 4090，NV50XX = RTX 5090（默认）；可多选要伪装的显卡 |
| 04 帧生成选项 | 渲染预设 / 帧生成倍率 / 画面一致性 |
| 05 运行日志 | 查找、校验、注入、写配置的实时记录 |
| 开始游戏 | 大号胶囊按钮：启动游戏并轮询注入；游戏运行中变成「退出游戏」，再点即关闭游戏 |

多显卡：勾选哪几张就只改哪几张；选择结果写进 `config.ini` 的 `[AdapterSpoof] Select=`（按 LUID，
拔插显卡或更新驱动都不会错位）。USB 便携屏、虚拟显示器会被识别并排除，不会误改名。

## 帧生成选项

| 选项 | 可选值 |
|---|---|
| 渲染预设 | 默认 / UI 重组 / 轻量插帧 |
| 帧生成倍率 | 2X / 3X / 4X / 5X / 6X（默认 4X） |
| 画面一致性 | 原厂 / 逐位 / 有损 / 最快 |

DLSS 超分不在启动器里提供，沿用游戏内设置。

## 配置文件与日志

exe 同目录下只有两个数据文件，都会自动生成：

| 文件 | 作用 |
|---|---|
| `config.ini` | 唯一配置：帧生成选项 + 显卡伪装 + 启动器状态（首次启动从内嵌模板生成） |
| `zzzdlssg.log` | 唯一日志：启动器、钩子、插件共同追加写入 |

`[AdapterSpoof]` 段由插件读取：

```ini
[AdapterSpoof]
Enabled=1
Fake=RTX 4090
; ';' 分隔的适配器 LUID，留空 = 自动规则命中的全部适配器
Select=
; 非空则按字面替换，留空 = 自动 20/30 系规则
Match=
```

已存在的 `config.ini` 不会被覆盖。日志每行格式为 `yyyy:mm:dd hh:mm:ss [来源] 内容`，
来源有 `[launcher]` 与 `[adapter spoof]` 两种，按标签就能只看一部分。

## 校验与签名

- 插件安装后由启动器对 **7 个 DLL**（loader + 6 个内核）做 SHA-256 比对，基准表编在 exe 里，
  交付目录不带任何哈希文件，装在本地的东西没法给自己背书。
- 安装后的 `dlssg_loader.dll` 与编进 exe 的哈希必须**逐字节一致**，否则卡片保持红色。
- exe 为自签测试证书签名，Windows 会显示「未知发布者」；这不影响使用。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击没反应 / 提示需要权限 | 清单要求管理员，在 UAC 里点「是」 |
| 首次运行 0/7 红灯 | 插件还没安装，点「下载插件」 |
| 注入失败：拒绝访问 (5) | 没拿到管理员权限（例如被计划任务以普通权限拉起） |
| 点「下载插件」失败 | 看「运行日志」的阶段与原因：测速 / 下载 / 校验 / 解包 / 打补丁；代理、fakeip、DNS 类网络问题也会在这里暴露 |
| 校验失败（会写明哪个文件不符） | 某个 DLL 被替换、损坏或缺失，点「下载插件」重装 |
| 游戏里没有帧生成选项 | 启动参数漏了 `-use-d3d12`，或没勾选显卡 |
| 显卡名没变 | 看 `zzzdlssg.log` 有没有 `[adapter spoof] rename` 行 |
| 点了「退出游戏」没关掉 | 启动器先发 `WM_CLOSE`，8 秒不退就强制结束；仍不行请手动结束 `ZenlessZoneZero.exe` |

排查更细的启动过程：设置环境变量 `ZZZDLSS_TRACE=1` 后运行，会在目录里写 `launcher-trace.log`。

## 卸载

游戏关闭后，删除启动器所在的整个文件夹即可——游戏目录没有写入任何文件，不会留下残留。

## 已知限制

- 只改 DXGI 的 `GetDesc` / `GetDesc1`；注册表、`EnumDisplayDevices` 拿到的仍是真实显卡名。
- 插件基于上游 0.4.1 的 `d3d12.dll`；上游大改版本需要等启动器更新。
- 自签证书只在本机证书库受信，换机器一律显示「未知发布者」。
- 首次安装必须联网，且需要能访问上游发布源。
- 因为使用进程注入，个别安全软件可能拦截或误报；如有疑虑请在隔离环境里先试。
